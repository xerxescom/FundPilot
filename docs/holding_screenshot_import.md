# 中信证券持仓截图导入

## 配置

在本地 `.env` 中填写阿里云百炼的视觉模型密钥：

```env
QWEN_API_KEY=你的百炼 API Key
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
QWEN_VL_MODEL=qwen-vl-plus
QWEN_TIMEOUT=90
```

配置后重启后端。该能力与 `AI_PROVIDER`、DeepSeek 日报配置相互独立；DeepSeek 仍只用于文本分析。

## 使用方式

1. 打开“我的持仓”，在“中信证券持仓截图导入”区域上传 PNG、JPG 或 WebP 截图（最大 10MB）。
2. 系统将图片仅在当前请求中转发给 Qwen-VL，并返回可编辑的识别草稿；图片不会写入 FundPilot 数据库。
3. 核对资产类型、代码、数量、成本价、现价/净值和市值，删除不确定的行后确认导入。
4. 导入结果会创建或更新手工持仓快照，并把截图价格写成对应日期的 `citic_screenshot` 行情来源。之后执行常规行情同步时，外部行情会覆盖同日期的截图价格。

## 保护规则

- 截图不是交易流水：不会创建虚构的买入、卖出、手续费或交易日期。
- 已有交易流水的资产会被跳过，避免覆盖由交易账本计算出的成本和持仓。
- 导入前请自行遮盖账户号、手机号、身份证明、资金密码提示等不需要识别的内容。
- OCR/视觉识别结果可能出错，确认导入前必须人工核对。
