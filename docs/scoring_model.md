# FundPilot 评分模型说明

FundPilot 使用 100 分规则评分模型，评分只用于基金筛选、观察和风险提示，不构成投资建议。

## 分层结果

- 综合评分：观察基金自身质量，覆盖收益、回撤、波动、稳定性、趋势、规模和交易状态。
- 可信度评分：衡量当前数据是否足以支撑评分判断，不直接改写综合分。
- 窗口信号：基于综合评分、可信度、近期趋势、回撤、波动和交易状态给出观察状态。
- 风险标签：列出导致评分或窗口信号降级的主要风险。
- 市场环境：使用主要指数近 1 月表现判断当前环境是否支持窗口信号。
- 同类比较：按自选行业或基金类型分组，比较收益、回撤、波动和夏普比率的综合百分位。
- 组合适配：使用持仓权重和基金相关性判断是否存在重复配置或集中度风险。

## 评分维度

- 收益质量：关注近 1 年收益，同时纳入近 1 月、近 3 月和近 6 月趋势。
- 风险控制：关注近 1 年最大回撤和年化波动率。
- 风险调整收益：使用夏普比率辅助判断收益是否来自更有效的风险承担。
- 稳定性：关注近 1 年上涨天数占比。
- 基金基础质量：关注规模、成立时间和基金档案完整度。
- 交易可用性：暂停申购、封闭或交易状态异常会触发窗口信号降级或阻断。

## 可信度评分

可信度评分独立于综合评分展示。以下情况会降低可信度：

- 关键指标缺失，例如收益、回撤、波动或胜率。
- 近期趋势指标缺失。
- 夏普比率缺失。
- 最新指标或净值日期偏旧。
- 净值历史不足 1 年。
- 基金规模、成立时间或申购状态缺失。

可信度等级分为：

- high：数据较完整，评分解释力较强。
- medium：数据基本可用，但需要结合风险标签观察。
- low：数据不足，不适合形成强窗口信号。

## 窗口信号

窗口信号不是买卖指令，只表示当前观察状态：

- favorable：窗口较好。
- watch：可以观察。
- wait_pullback：等待回撤或趋势确认。
- cautious：谨慎观察。
- blocked：当前不具备操作条件。

高综合分不会自动得到最高窗口信号。若可信度不足、数据过期、关键指标缺失、回撤偏深、波动偏高或交易状态异常，窗口信号会被降级。

API 同时返回 `risk_flags` 和 `risk_flag_labels`。前者用于程序判断，后者用于界面展示。

## 同类、市场与组合覆盖

同类比较、市场环境和组合适配不改写基金自身综合评分，只影响窗口信号和风险提示：

- 同类样本不足 3 只时，系统不使用同类排名影响窗口信号。
- 同类百分位偏低时，较强窗口信号会降级为等待确认。
- 市场偏弱时，较强窗口信号会降级为观察或等待确认。
- 基金已在组合中且权重偏高时，会触发集中度风险。
- 与组合或自选基金相关性过高时，会触发重复配置风险。
- 没有市场或持仓数据时，系统采用中性解释，不强行加分。
