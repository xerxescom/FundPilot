# 演示脚本

FundPilot 是一个本地基金投研助手。它不做买卖决策，只做数据监控、量化指标、规则评分、风险提醒、持仓跟踪和谨慎的 AI 简报。

## 演示主线

1. 打开 Vue 今日驾驶舱，查看今日待办、关键风险、数据健康和最新日报。
2. 进入“自选基金”，添加一只基金代码，确认系统记录基金名称和行业/主题。
3. 点击“一键分析”，说明标准流程是同步净值、计算指标、计算评分、生成基金解释。
4. 进入“基金详情”，查看基金档案、分析状态、净值、回撤、日涨跌幅和评分原因。
5. 进入“评分排行”，说明规则评分模型和评级区间。
6. 进入“基金对比”，选择 2-5 只基金横向对比收益、回撤、波动、评分和行业主题。
7. 进入“我的持仓”，录入一笔买入记录，展示自动汇总份额、平均成本、组合市值、持仓占比和组合诊断。
8. 进入“相关性分析”，查看高相关组合，说明如何发现重复配置。
9. 返回今日驾驶舱，处理未读预警并生成 AI 简报。
10. 进入“报告历史”，查看历史日报和输入摘要。
