# FundPilot 5 分钟演示脚本

## 1. 项目定位

FundPilot 是一个本地单用户基金投研助手。它不做买卖决策，只做数据监控、量化指标、规则评分、风险提醒和谨慎的 AI 简报。

## 2. 演示路径

1. 打开 Streamlit 看板，先看首页的数据状态、市场概览、推荐关注 Top 5 和风险提醒。
2. 进入“自选基金”，添加一只基金代码，确认系统记录基金名称和行业/主题。
3. 触发净值同步，说明数据来自 AKShare，失败时可用 Eastmoney 做对账或备用。
4. 进入“基金详情”，展示净值、回撤、日涨跌幅，以及收益率、波动率、夏普比率和评分。
5. 进入“评分排行”，说明规则评分模型和评级区间。
6. 进入“数据质量”，展示净值健康状态，并对单只基金执行 AKShare 与 Eastmoney 对账。
7. 进入“基金对比”，选择 2-5 只基金横向对比收益、回撤、波动、评分和行业主题。
8. 进入“我的持仓”，录入一笔买入金额和成交净值，展示自动汇总份额、平均成本、组合市值和收益率。
9. 进入“相关性分析”，选择两只基金对比，说明如何发现重复配置。
10. 进入“AI 简报”，生成日报，展示模型名称、fallback 状态、失败原因和输入数据摘要。
11. 进入“报告历史”，查看历史日报和输入摘要。
12. 进入“任务中心”，展示手动任务和最近任务日志。

## 3. 技术讲解要点

- FastAPI 提供结构化接口，Streamlit 负责本地看板。
- PostgreSQL 保存净值、指标、评分、持仓、预警、AI 报告和任务日志。
- Pandas 计算收益率、最大回撤、波动率、夏普比率和相关性。
- 评分模型使用规则分，不依赖大模型，保证可解释。
- AI 只基于结构化数据生成总结，失败时使用规则兜底，并过滤直接买卖建议。
- Docker Compose 可以启动数据库、后端和看板。

## 4. 演示边界

FundPilot 不承诺收益，不给出直接买入、卖出或重仓建议。免费数据源可能有延迟或字段变化，真实生产环境应继续加强多数据源兜底和数据校验。
